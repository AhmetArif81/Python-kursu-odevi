🚀 Projeler Nasıl Çalıştırılır?

Bu depodaki kodları kendi bilgisayarınızda çalıştırmak için:

Bilgisayarınızda Python'un kurulu olduğundan emin olun.

Bu depoyu bilgisayarınıza klonlayın veya indirin:

git clone [https://github.com/AhmetArif81/depo-adiniz.git](https://github.com/AhmetArif81/depo-adiniz.git)


Terminal veya Komut İstemcisi üzerinden dosyanın bulunduğu dizine gidin ve dosyayı çalıştırın. Örneğin:

Not: Hava durumu uygulamasının çalışması için sisteminizde requests kütüphanesinin kurulu olması gerekebilir (pip install requests).
